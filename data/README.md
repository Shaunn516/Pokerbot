# Data

Large training datasets are not committed to this repository.

The original project used supervised fine-tuning JSON datasets for 6-handed No Limit Texas Hold'em decisions. Those files are useful for future model training or evaluation, but they are not needed for the public DeepSeek-only MVP.

Future data work should:

- Host large datasets externally.
- Document download links and checksums.
- Keep raw and processed data out of Git unless intentionally publishing a small sample.
- Add a small anonymized sample dataset only if it is useful for tests or documentation.
